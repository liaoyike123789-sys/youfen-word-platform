# 优分单词平台 测试计划

| 项目 | 内容 |
|---|---|
| 项目名称 | 优分单词平台（Web + 小程序 + 后端接口） |
| 测试版本 | v1.0.0 |
| 测试周期 | 2026-04 ~ 2026-05 |
| 测试人员 | 廖奕科 |
| 文档版本 | v1.0 |

## 1. 测试目标

围绕 Spring Boot 单词学习平台的 **用户认证、单词查询、学习记录、数据统计** 四大模块，完成从接口调试、功能测试、问题跟踪到回归验证的全流程实践，验证：

1. 32 个核心接口在正常 / 异常 / 边界输入下的行为符合预期；
2. Web 端与小程序端在部署、跨域、登录态等场景下可用；
3. 发现的问题能在禅道中闭环跟踪，修复后回归通过。

## 2. 测试范围

| 模块 | 是否纳入 | 说明 |
|---|---|---|
| 用户注册 / 登录 / 登出 / 当前用户 / 改密 / 资料 | 是 | 6 个接口 |
| 单词 CRUD / 分类 / 搜索 / 字母分组 | 是 | 11 个接口 |
| 今日学习 / 标记认识 / 学习记录 / 错题本 / 打卡 | 是 | 8 个接口 |
| 总览 / 今日 / 趋势 / 掌握 / 连续 / 正确率 | 是 | 6 个接口 |
| 健康检查 / Swagger / H2 Console / CORS | 是 | 4 项 |
| 小程序前端 UI | 部分 | 以接口联调 + 真机走查为主，不做像素级还原 |
| 性能压测 | 是 | JMeter 对 `/api/words` 做基础并发验证 |
| 安全（SQL 注入、越权、Token 伪造） | 是 | 覆盖关键用例 |
| 部署运维（Linux 日志、Docker、MySQL 切换） | 是 | 作为问题排查与部署演练 |

## 3. 测试环境

| 项 | 配置 |
|---|---|
| 后端 | Spring Boot 3.2.5 / JDK 17 / 端口 8080 |
| 数据库 | 开发期 H2 内存库（MySQL 兼容模式）；演示环境切 MySQL 8.0 |
| 接口调试 | Postman、Swagger UI (`/swagger-ui.html`)、Fiddler 抓包 |
| 自动化 | JUnit 5 + RestAssured（`test-automation/`） |
| 压测 | Apache JMeter |
| 缺陷管理 | 禅道 |
| 运行系统 | Windows 11 开发机；部署演练用 CentOS 7 / Ubuntu 22.04 |

## 4. 测试策略与通过标准

| 测试类型 | 策略 | 通过标准 |
|---|---|---|
| 功能测试 | 基于接口契约 + 业务场景设计用例 | P0 用例 100% 通过，P1 通过率 ≥ 95% |
| 接口测试 | Postman 手工 + RestAssured 自动化 | 32 个接口全部冒烟通过 |
| 异常 / 边界 | 空值、超长、非法枚举、不存在 ID、越权 | 不出现 500 未捕获异常 |
| 兼容性 | Chrome / Edge / 微信小程序开发者工具 | 核心流程可用 |
| 性能 | JMeter 50 并发压 `/api/words` 30s | 90% 响应 < 500ms，错误率 < 1% |
| 回归 | 每个 bug 修复后跑相关模块用例 + 冒烟 | 回归用例全通过 |

## 6. 准入 / 准出

**准入**：
- 后端服务在测试环境可正常启动，H2 / MySQL 连接成功；
- Swagger 文档可访问，接口字段与开发对齐；
- 测试数据初始化脚本（`data.sql`）执行成功。

**准出**：
- P0 用例全部通过，无遗留致命 / 严重 bug；
- 遗留 bug 均有产品或负责人确认的处理意见；
- 自动化冒烟脚本在干净环境可一键跑通；
- 测试报告与问题排查记录归档。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| H2 与 MySQL 语法差异 | 演示环境切 MySQL 后个别 SQL 报错 | `application.yml` 注释中记录切换步骤；提前在 MySQL 上跑一遍冒烟 |
| Token 用内存 Map 存储 | 重启服务后所有用户掉线 | 演示环境接受；README 标注生产应换 Redis |
| 密码明文存储 | 安全风险 | 演示版接受；README 标注生产应 BCrypt |
| 小程序端真机差异 | 部分机型布局 / 请求异常 | 优先覆盖微信开发者工具 + 1 台真机走查 |
