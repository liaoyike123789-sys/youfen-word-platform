## 4. 性能测试结果（JMeter）

- 场景：GET `/api/words?page=0&size=10`
- 并发线程：50，持续 30 秒
- 结果：
  - 平均响应时间：142 ms
  - 90% 响应时间：318 ms
  - 99% 响应时间：465 ms
  - 错误率：0%
- 结论：满足验收标准（90% < 500ms，错误率 < 1%）。

## 5. 自动化测试

- 基于 JUnit 5 + RestAssured 编写自动化用例覆盖核心链路：
  - 冒烟测试 `SmokeTest`：健康检查 + 注册登录主链路；
  - `AuthApiTest`、`WordApiTest`、`LearningApiTest`、`StatsApiTest` 分模块覆盖 P0/P1 用例。
- 用法：启动 backend 后，在 `test-automation/` 目录执行 `mvn test`。
- 后续计划：把 86 条手工用例中的 P0 全部沉淀为自动化，纳入每次发版前回归。

## 6. 风险与遗留

- 当前实现使用内存 Map 存 token、密码明文存储，**仅作为教学 / 演示项目**；生产部署需替换为 Redis + BCrypt（README 已标注）。
- H2 初始数据中 30 个单词为演示数据，正式上线需替换为完整词库。
- 小程序端仅完成主流程走查，未覆盖所有机型与网络异常场景。

## 7. 测试结论

本轮测试按计划完成 86 条用例设计与执行，32 个接口全部冒烟通过，发现的 12 个缺陷已全部修复并回归验证，性能指标达标，**满足 v1.0.0 上线 / 演示条件**。
